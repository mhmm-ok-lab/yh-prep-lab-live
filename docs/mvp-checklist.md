# MVP-checklista

Den här listan visar vad som redan finns i nuvarande MVP.

## Klar status

- [x] Dagens 30-45 min-pass med Sprint A/B-logik
- [x] Tre separata spår: Nackademin UX, IT-Högskolan IT-säkerhet och Programmering 1/A
- [x] Gemensam kärna för alla spår
- [x] Lägen: Lär, Drill och Tidsprov
- [x] Frågebank med filter för spår, ämne, nivå och källnivå
- [x] Drill-start från spårvy
- [x] Drill-start från filtrerad frågebank
- [x] Mockprov för Nackademin på 60 min
- [x] Mockprov för IT-H på 90 min med Del 1 och Del 2
- [x] Timer för aktiva pass
- [x] Autosparning av aktivt pass
- [x] Avslut och rättning av pass
- [x] Resultatvy med poäng och svaga områden
- [x] Spårprogress baserat på tidigare pass
- [x] Evidence-kort med källa, tillförlitlighet och verifieringsdatum
- [x] Svar och förklaringar direkt i frågebanken
- [x] Sparade studiepass i lokal lagring
- [x] Snabbflikar: UX, IT, Prog, Logik
- [x] Logik-flik med egen drillstart
- [x] Ready-o-meter i översikt
- [x] UX scenario-generator med workflowstöd
- [x] Frågor tillagda från Gemini-exempel (IKEA-case, OSI-router, Boolean)
- [x] Programmeringstillägg: code tracing och debugging-frågor
- [x] Mini-check 10 min (balanserad mix)
- [x] Roadmap-vy i appen för stora steg och nuläge
- [x] `npm run verify` för standardverifiering

## Delvis klar

- [~] Mer komplett frågebank (40 frågor nu, fortsätter byggas ut)
- [~] Fler mockprov och fler varianter per spår (5 mockprov nu)
- [ ] Tydligare återkoppling per svagt område
- [ ] Bättre jämförelsevy mellan olika pass

## Inte klart än

- [ ] Export av resultat
- [ ] Delning av plan eller resultat utanför appen
- [ ] Inbyggd import av extern Gemini-plan

## Kort läsning

Om du bara vill veta läget snabbt:
- Kärnflödet för träning finns.
- Tidsprov och rättning finns.
- Progress och källstöd finns.
- Det som främst saknas är större innehållsmängd och mer leveransyta runt resultat och delning.
