# Roadmap - YH Prep Lab

Det här är övergripande planen i stora steg.

## Status nu

- Klar: Stabil grund
- Klar: Lugn testmotor
- Klar: Innehållsbredd
- Pågår: Adaptiv coachning
- Nästa: Publiceringsspår

## Steg 1 - Stabil grund (klar)

- Mobile-first grundlayout
- Byt/skapa användare
- Lokal progress och återupptagning av aktiv session

## Steg 2 - Lugn testmotor (klar)

- Mini-test med tydlig radio-layout
- Mjuk tidsindikator
- Minskat visuellt brus i aktiv session

## Steg 3 - Innehållsbredd (klar)

- Utökad frågebank i UX, IT och Programmering
- Fler mockprov (kort + längre varianter)
- Tydligare "gemensamt mellan proven"-stöd i research

Definition of done:
- Minst 45-60 kvalitetsfrågor totalt
- Minst 2 snabbmocks + 3 längre mocks
- Bättre täckning av svåra ämnen per spår

## Steg 4 - Adaptiv coachning (pågår)

- Mer exakt rekommendation efter svagheter
- "Nästa bästa pass" med tydlig motivering

Definition of done:
- Varje avslutat pass ger ett konkret nästa pass
- Rekommendationen byter fokus när felmönster ändras

## Steg 5 - Publiceringsspår (nästa)

- Stabil länk och enklare deploy
- Standardiserad verifiering före publicering

Definition of done:
- Samma länk fungerar konsekvent på mobil
- `npm run verify` körs inför varje publicering
