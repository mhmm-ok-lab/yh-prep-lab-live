# UX Build Log - 2026-04-03

## Session Summary
- Build focus: Mobile-first ombyggnad efter konkret användarfeedback.
- User goal: Snabb och trygg mobilanvändning inför antagningsprov.
- UX risk noticed: För stora knappar och för tät information gav låg läsbarhet och hög feltouch-risk.
- Constraint that guided the work: viktig information måste få plats på en mobilskärm utan att allt ser ut som ett tätt rutnät.

## Decisions Made
- Decision: Flytta till en tydlig mobile-first baslayout och göra desktop till enhancement.
  Why: Tidigare layout kändes som desktop nedskalad.
  Type: Requirement

- Decision: Visa kritisk information först i en "Snabbstart idag"-yta och lägg resten i utfällbara sektioner.
  Why: Minska kognitiv last på första skärmen.
  Type: Requirement

- Decision: Göra knappar mer kompakta men behålla tydliga tryckytor och separation.
  Why: Undvika både visuellt brus och feltouch.
  Type: Requirement

- Decision: Behålla bottom-nav på mobil men göra knapparna kortare och mer kompakta.
  Why: Bibehållen tumzon med lägre visuellt utrymmeskrav.
  Type: Recommendation

- Decision: Låta detaljer ligga bakom utfällbara sektioner i översikt och rapportvy.
  Why: Hålla första skärmen fokuserad på startpunkt, status och nästa steg.
  Type: Requirement

- Decision: Minimera breda CTA-rader och i stället gruppera handlingar i små, separata enheter.
  Why: Minska risken att användaren trycker fel när knapparna ligger för tätt.
  Type: Requirement

## Language and Semantics
- Label discussed: "Snabbstart idag"
  Chosen wording: "Snabbstart idag"
  Why it is clearer: Signal om vad användaren ska göra nu, utan tekniska termer.
- Label discussed: "Dagens pass"
  Chosen wording: "Snabbstart idag"
  Why it is clearer: Mer direkt handling än en neutral rubrik.

## Observations from Live Use
- What user saw: "Ingen skillnad" trots tidigare ändring.
- Why it mattered: Visade att förändringen inte var tillräckligt tydlig i faktisk mobilupplevelse.
- Follow-up: Gjordes om till hårdare mobile-first struktur med mer aggressiv prioritering av innehåll.
